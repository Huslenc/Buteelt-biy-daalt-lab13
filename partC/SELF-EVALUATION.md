# Self-Evaluation — Бие даалт 13

## 1. Хэрэв шалгалт өнөөдөр болбол би энэ кодыг өөрөө бичиж чадах уу?

**Хэсэгчлэн — тайлбартай:**

Чадах зүйл:
- Express route, controller, middleware бүтэц — ойлгосон, өөрөө бичиж чадна
- SQLite schema, PRAGMA тохируулалт — ойлгосон
- Jest тестийн бүтэц, beforeAll/afterAll — ойлгосон

Хэцүү байх зүйл:
- `db.transaction()` syntax-ийг documentation харалгүй бичихэд андуурч магадгүй
- Mermaid диаграмын нарийн syntax санахад хэцүү
- OpenAPI 3.0 spec-ийг бүрэн гараар бичих хэцүү

Дүгнэлт: Архитектур, logic-ийг ойлгосон. Syntax-ийн нарийн зүйлд documentation хэрэгтэй болно — энэ хэвийн.

## 2. Дахин хийнэ гэвэл юуг өөрөөр хийх вэ?

**TypeScript ашиглах:** JS-ийн type алдааг AI-ийн санал болгосон кодод олоход хэцүү байсан. TypeScript байсан бол compiler өөрөө барьж байсан.

**CLAUDE.md-ийг эхнээс нарийн бичих:** Session дундаас AI response format "мартсан" учир CLAUDE.md-д response format-ийг жишээтэй нарийн бичсэн байсан бол дахин тайлбарлах цаг хэмнэх байсан.

**AI session log-ийг дор нь хадгалах:** Session дуусахаас өмнө товчлон хадгалах заншилтай болох — сүүлд санах нь хэцүү.

---

## 3. Энэ туршлагаас юу сурсан бэ?

**"Verify, don't trust" практикт ойлгосон:** AI код үүсгэдэг, гэхдээ project-ийн context-ийг бүрэн мэддэггүй. Жишээ нь `closeDb()` орхигдох, response format буруу байх зэрэг алдааг өөрөө олж засах шаардлагатай.

**AI workflow нь хурдасгагч, орлуулагч биш:** Scaffold хурдан гарна, гэхдээ business logic, security шалгалт хүний оролцоо шаарддаг. Энэ хоёрыг ялгаж сурсан нь хамгийн чухал сургамж.

**Commit дисциплин чухал:** Өдөр бүр тодорхой зорилготой commit хийснээр ажлын явцыг хянах, буцаах боломжтой болсон. "Нэг том commit" хийх хуучин зуршлаасаа гарсан.
